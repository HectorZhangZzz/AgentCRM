## 覆盖场景与限制

| 场景 | 已有验证 | 不能据此推定 |
|---|---|---|
| 去重与幂等 | 相同字节复用原件、同 key 重试、不同内容拒绝、业务重复保护 | 相似图片语义去重或所有重复表达都能自动识别 |
| 实体与项目 | 同名同音不自动合并、多客户/项目独立归属、稳定 ID | 自动工商核验、人员身份已匹配或合同主体已确认 |
| 证据与冲突 | 文字引文/偏移、版本保护、差异与来源、失败原子回滚 | 引文存在就代表信息真实或模型语义必然正确 |
| 人工纠正 | 名称更正保留旧名/ID；安全范围内归属移转后采用正确结果 | 复杂多源或产品断言全部自动拆分，仍可能有 `pending` |
| 六态任务 | 完成/取消退出默认列表、改期留历史、owner/期限可空 | 任务完成等于采购/库存/项目验收完成，或已经开启提醒 |
| 接口和权限 | 真实本机 HTTP、官方 MCP stdio 和 CLI；reader 拒写、角色及 Host/Origin 边界 | 实际 WorkBuddy/DOTS 客户端已连接、云端能直连本机或同账户形成沙箱 |
| 500 MB 原件 | 实际 500,000,000 字节收发、重复复用、超限拒绝、中断/篡改检测 | 文件已解析、进入全文检索或模型能读取整份内容 |
| 产品资料 | 身份/单父关系/跨父同名、要求/评估/能力、条件/来源、不继承、幂等及恢复 | 产品技术真实性已独立认证、SKU/报价/产品投影已实现 |
| 产品页面工作流 | 草稿、重复提交、不确定响应、401 后核对同一请求、开关与入口边界 | 本轮已重新完成真实浏览器视觉检查或可进行任意复杂编辑 |
| 源码发布 | 无数据允许清单、已识别敏感模式、独立净化历史及模拟发布拒绝路径 | 规则能发现任意文档内的隐私，或远端已经收到本轮版本 |

- **完整运维备份与全新目标恢复：已演练。** 比较逻辑表内容、稳定 ID、来源/历史/关联以及原件字节与 SHA256；包含大原件恢复与下载核对。它不等于跨操作系统恢复，也不由本轮 4 项运维边界测试重新证明。

## 接收者如何复验

先按 [INSTALL.md](INSTALL.md) 与 [THIRD_PARTY.md](THIRD_PARTY.md) 准备依赖和上游。`npm test` 读取本机测试所需配置，通过已有数据库角色建立随机命名的全新合成库；该角色需具备所需测试建库权限。源码包没有私有配置，未初始化和未准备运行时的目录不能直接完成全部测试。

```bash
npm test
python3 ops/test_manage.py
python3 ops/test_share_package.py
python3 ops/test_github_backup.py
python3 ops/test_prepare_twenty.py
```

成功的完整自动化默认清理本轮合成数据库和大原件；失败保留现场，调试可用 `CRM_TEST_KEEP_DATA=1`。不要为让测试通过而删除正式资料、覆盖恢复目标或扩大权限；权限不足时先说明条件，不擅自升级。

浏览器流程需新的独立合成预览与匹配 Chrome 条件，详见 [PRODUCT_LIBRARY.md](PRODUCT_LIBRARY.md)。完整运维恢复只进入全新目录/数据库，并核对原件、稳定 ID、关系及历史；不能只生成压缩包就宣布恢复成功。

详细运行结果保存在执行者本机的 `test/results/` 等私有验证位置，**不进入源码分享包或 GitHub**。本文件不链接被排除的运行产物；测试源码和复现说明随包保留，新的执行者产生自己的结果。正式部署还须按实际宿主、系统、数据规模和授权范围补齐验证。
