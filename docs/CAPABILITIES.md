# Agent CRM 当前能力与边界

本表供新维护者、宿主 Agent 和朋友安装时判断可交付范围。依据是源码 **0.1.4 / 工具契约 1**、[CONTRACT.md](CONTRACT.md) 和 [TEST_RESULTS.md](TEST_RESULTS.md) 中的已执行记录；本轮整理未读取业务库或私有配置，不据此断言某个实例当前在线或功能已开启。业务目标见 [REQUIREMENTS.md](REQUIREMENTS.md)。

状态含义：**已实现**是源码存在且有相应验证记录；**可选/默认关闭**需显式配置后才可用；**方案待实现**只有需求或设计；**目标未实测**不能以通用协议通过代替实际环境验收。实现状态与某台电脑的启用状态分别判断。

## 已实现的基础闭环

| 能力 | 实现依据 | 证据与实际边界 |
|---|---|---|
| 原件持久保存 | `src/material-storage.mjs`、`crm_ingest`、流式上传/下载 | SHA256 去重；来源/时间/质量标记；真实 500,000,000 字节上传下载及超限拒绝有历史测试，不代表模型能读完 |
| 客户/联系人/项目/组织/问题 | `src/domain.mjs`、`migrations/001_initial.sql` | 稳定 ID、有证据关系；同名同音不自动合并。业务角色依赖准确录入，不是自动工商识别 |
| 提议与事务提交 | `crm_propose`、`crm_commit` | 幂等、版本、冲突、证据、原子回滚；普通更新无需 owner。语义真实性仍需宿主判断 |
| 当前档案与历史查询 | `crm_entities`、`crm_customer`、`crm_materials`、`crm_evidence` | 可读当前事实、时间线、关联及覆盖。简报由宿主生成，服务不自动生成或存档报告 |
| 文字与条件匹配 | 实体名称/别名/当前事实、材料文字与时间条件 | 基础查询可用；分页和未解析附件必须披露，不能称为完整语义检索 |
| 六态任务与历史 | `crm_tasks`、`crm_task_update` | 区分行动方/等待对象；完成与取消默认隐藏；改期和版本留痕，不自动创建提醒 |
| 名称维护 | owner 专用 `crm_entity_rename` | 保留稳定 ID、旧名、来源与审计；不会合并实体或证明合同主体 |
| 归属纠正 | owner 专用 `crm_reassign` | 安全移动单材料独立支持的内容；复杂多源/产品断言可能返回 `pending`，不是任意拆分全自动完成 |
| 本机管理台与领域接口 | `src/server.mjs`、`src/mcp.mjs`、`src/cli.mjs` | HTTP、MCP stdio、CLI 共用领域；loopback、角色与认证控制，不是公开远程 MCP 服务 |
| 常驻与健康检查 | `ops/supervise.py`、`ops/install-user-service.py` | Linux 用户服务、登录后常驻及故障恢复有记录；不执行后台 AI，不保证断电/休眠或退出登录后持续在线 |
| 备份、恢复与导出 | `ops/manage.py` | 逻辑数据、原件、清单/哈希和版本；全新目标恢复有验证。个人私有备份与朋友源码分享不同 |
| 无数据源码包与 GitHub 净化 | `ops/share_package.py`、`ops/github_backup.py` | 允许清单、排除私有数据和旧敏感调试文件、ZIP/树校验有测试；离线测试或本机准备不等于本轮上传完成 |
| Twenty 兼容投影 | `src/twenty-projection.mjs` | 有限客户/联系人/商机投影及外部修改保护；可重建，不是事实源。原生前端完整验收、全量投影成功不在交付承诺内 |

## 可选产品资料库：代码已实现，通用默认关闭

| 能力/开关 | 当前实现 | 使用边界 |
|---|---|---|
| `productLibraryEnabled` | 显式布尔值为 true 才注册产品工具并执行可选 002 | 默认 false；既有 002 关闭功能后仍保留并核验 checksum，不删产品或降级库 |
| 产品/型号/版本 | 独立身份、单父层级、有证据客户/项目关联 | 同名判重结合父身份；关联不等于采购/适配；不跨版本继承能力 |
| 要求/评估/能力 | `set_product_assertion`、`crm_product` | 要求带客户/项目上下文；评估未知/待验证；能力需 `reviewed:true` 和文字依据。服务不独立验证性能或证书真实性 |
| `productUiEnabled` | 独立默认 false；开启后提供 `/products` | 页面开关不触发 002；领域未启用时页面应准确说明不可用，不擅自改配置 |
| 页面新增与回读 | 层级浏览、来源、三类记录、关系及幂等工作流 | 合成浏览器验收已有；已有记录复杂修改/父归属调整仍需领域工具审阅 |
| 产品备份恢复 | 复用现有实体、关系、事实版本和原件 | 隔离恢复及正式升级保护有历史记录；不能直接用旧代码回退已应用的 002 |

这些是代码和历史验证能力，朋友安装时须自己决定并验收开关。产品专属 Twenty 投影、SKU、完整报价、自动能力提取和复杂分类尚未实现。步骤见 [PRODUCT_LIBRARY.md](PRODUCT_LIBRARY.md)。

## 已确定但尚未交付的需求

| 方向 | 现有基础 | 尚缺什么/不能承诺什么 |
|---|---|---|
| 每位新增联系人核查 | 姓名、组织与来源可人工归档 | 尚无持久研究任务、领取租约、研究层/身份映射及专用 `crm_research_*` 工具；不能声称每次新增已自动核查 |
| 主动“公司＋姓名”调研 | 宿主可在授权范围内研究并用现有入口保存 | 同一研究闭环未实现；公司/人员关联不明确时不采用，不能凭旧 Skill 或搜索摘要补档 |
| 天眼查等外部提供方 | [整合方案](SEEKINGPERSON_INTEGRATION.md) 已审查工具与数据流 | 实际账号、权益、费用、凭据隔离与宿主连接未验证；没有随 CRM 安装即生效的真实查询服务 |
| 方案专门模型与版本 | 项目事实、变更历史、原件关联可用 | 专门方案身份、版本、当前有效状态及段落检索待建，不能把通用事实历史称为完整方案管理 |
| 文档正文与多媒体理解 | 任意受限原件可保存，文字可由宿主提供 | PDF/Office 正文提取、OCR、音频转写、视频理解不是已接入的服务能力 |
| 中文全文及语义检索 | 简单文字/条件匹配 | 中文全文、段落索引、本地 embedding、pgvector 尚未实现；没有独立向量数据库部署 |
| 微信/外部批量连接器 | 可明确导入已取得材料 | 没有自动读取微信缓存、全量聊天/附件同步或后台采集；登录微信不等于已归档 |
| 全量聊天与报告归档 | 显式材料保存入口 | 不自动保存所有宿主对话/办公报告，不以聊天记忆填补数据库 |
| 提醒与微信事件通知 | 任务与状态已保存 | 事件判定、调度、发送、失败反馈及送达链路未完成验收；任务不会自动开启提醒 |
| 主机巡检/远程可用性 | 本地进程监督与健康状态 | 不能当成周期硬件巡检、关机风险预警、远程访问或 7×24 保证 |
| 异地云盘备份 | 本地完整备份及全新目标恢复 | 云盘上传、加密、权限和恢复演练未交付，不默认上传个人数据 |

SeekingPerson 的研究设计是“每位新增人员初步核查＋主动指定调研”，不是默认批量找新客户。外部资料不明就不采用；实施前仍需明确提供方、执行方式和预算。其原安装器、社交采集脚本和全部 Skill 未并入 CRM 默认运行时。

## 宿主与跨平台边界

| 目标 | 本项目已交付 | 尚需验收 |
|---|---|---|
| 通用 MCP stdio / CLI | 官方 MCP 客户端、HTTP/CLI 共契约验证；配置生成器 | 每个实际宿主的命令执行、角色、材料覆盖与写入闭环 |
| WorkBuddy | JSON 配置模板与生成器、通用协议验证 | 未完成 WorkBuddy 目标客户端实接；不能把配置片段称为发布连接器 |
| DOTS / Codex | Codex TOML、DOTS/通用 JSON 配置形状 | DOTS 是用户对目标入口的称呼，不能视为独立官方兼容认证；目标客户端仍需实际调用 |
| Hermes / OpenClaw | 通用接入说明与配置输出 | 尚未实接；不为宿主另建事实库 |
| Ubuntu 24.04 x86_64 | 原生 PostgreSQL/Redis/Node 运行路线；同系统隔离恢复 | 新机器仍需匹配运行时、建立私有实例并核验恢复；源码包不携带运行依赖 |
| Windows + WSL2 | `wsl.exe` stdio 桥接配置和安装路线 | 未进行真实 Windows/WSL 完整安装及恢复验收；依赖在目标 Linux 环境安装 |
| Windows 原生 | 无完整后端适配 | POSIX 文件锁、进程/服务管理及运行时需要改造；不是双击即装的 Windows 程序 |
| Docker / Docker Desktop | 适配设计与限制说明 | 没有已验收的 Compose 部署；网络白名单、进程生命周期、持久挂载及恢复需适配，不能假定数据库已在容器中 |

详见 [HOSTS.md](HOSTS.md)、[INSTALL.md](INSTALL.md) 与 [WINDOWS_DOCKER.md](WINDOWS_DOCKER.md)。本地 `127.0.0.1` 只能代表执行端本身；云端宿主不能自动访问用户电脑。公开部署、扩大监听和权限不属于默认安装步骤。

## 验证依据与重新验收

本轮源码整理于 2026-11-11 复跑完整自动化 69 项、运维边界 4 项、分享边界 7 项、GitHub helper 离线边界 15 项及固定上游取得边界 7 项，合计 **102 项通过**；其中完整自动化包括真实 500 MB 原件回归。另有产品页面合成 Chrome 20 组检查及完整备份恢复的历史记录；本轮未重新执行这些浏览器与完整运维恢复演练。具体日期、命令与边界见 [TEST_RESULTS.md](TEST_RESULTS.md)，不能用这些结果证明未测试宿主或平台已经可用。

源码分享不包含 `test/results/`、合成数据库或截图，避免把运行资料随代码发布；验收方法与测试源码保留。接收方在安装依赖后可按维护说明运行：

```bash
npm test
python3 ops/test_manage.py
python3 ops/test_share_package.py
python3 ops/test_github_backup.py
python3 ops/test_prepare_twenty.py
```

测试需要匹配的运行时与测试数据库条件，使用隔离合成资料，不能重置正式库。真实 UI 流程需独立合成预览和浏览器条件，不能为通过测试清空已有客户或沿用正式客户作为输入。

跨机器上线还应独立验证完整备份恢复、角色边界、实际宿主调用、检索覆盖和原件下载。模型理解正确性不能由单元/集成测试保证；有来源、未知标记、冲突与人工复核始终是业务要求。
