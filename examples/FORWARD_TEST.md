# 给新 Agent 的独立验证请求

使用项目内 `skills/agent-crm/SKILL.md` 和当前可发现的领域工具，在预先提供的**独立合成测试实例**完成下面用户请求。不要读取旧聊天、验收答案、真实资料或私有 owner 配置。允许读这两个合成原件并向测试库做 writer 范围内的写入；遇 owner 操作只报告所需决定。

> 请把 `examples/01-visit.txt` 和 `examples/02-update.txt` 依次归档、更新相关客户档案。第一次材料请重试上传一次，确保不会因重试重复建档。然后告诉我星河实验室当前的项目、数量、卡点、拜访安排及未完成承诺，并给出值得推进的三件事。重要结论附证据，说明哪些内容还不能确认。星禾实验室也请保留为单独候选。

完成后，另起一个没有旧对话上下文的读取 Agent，只给 Skill 与只读工具连接，提出：

> 请从数据库读取星河实验室的当前情况并写一份拜访准备简报。请说清查了什么、没读到什么、未知什么，附重要依据。

保存实际调用、返回 ID、错误与最终简报到测试结果目录，不含凭据。不得为得到预期结果直接改 SQL；服务拒绝的业务行为要如实报告。不要将只完成本机新上下文测试写成已完成第二家产品的迁移。
